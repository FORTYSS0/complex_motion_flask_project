Отчёт по естественному способу задания движения (ЕСЗД)

1. Исходные данные

Движение точки в декартовой системе координат задано уравнениями:

\[ x(t) = 8\cos\left(\frac{\pi t^2}{3}\right), \qquad y(t) = 16\sin\left(\frac{\pi t^2}{3}\right) \]

При естественном способе задания движения используются:

  • Дуговая координата \(s(t)\) - расстояние, пройденное точкой вдоль траектории;
  • Скорость \(V(t) = \dot s(t)\) - всегда направлена по касательной к траектории;
  • Касательное ускорение \(a_\tau = \dot V(t)\) - характеризует изменение модуля скорости;
  • Нормальное ускорение \(a_n = \dfrac{V^2}{\rho}\) - характеризует изменение направления скорости;
  • Радиус кривизны \(\rho\) - определяет степень искривления траектории.

2. Кинематические характеристики в естественном виде

2.1 Производные координат по времени (\(\dot x,\ \dot y,\ \ddot x,\ \ddot y\))

Все характеристики при естественном способе задания движения выражаются через производные декартовых координат. Найдём их явно. Исходные уравнения:

\[ x(t) = 8\cos\frac{\pi t^2}{3}, \qquad y(t) = 16\sin\frac{\pi t^2}{3}. \]

Первые производные (скорости). По правилу дифференцирования сложной функции \(\frac{d}{dt}\cos u = -\sin u\cdot\dot u\), где \(u=\frac{\pi t^2}{3}\), \(\dot u = \frac{2\pi t}{3}\):

\[ \dot x = -8\sin\frac{\pi t^2}{3}\cdot\frac{2\pi t}{3} = -\frac{16\pi t}{3}\sin\frac{\pi t^2}{3}, \] \[ \dot y = 16\cos\frac{\pi t^2}{3}\cdot\frac{2\pi t}{3} = \frac{32\pi t}{3}\cos\frac{\pi t^2}{3}. \]

Вторые производные (ускорения) — дифференцируем ещё раз (произведение \(t\) на тригонометрическую функцию, правило \((uv)'=u'v+uv'\)):

\[ \ddot x = -\frac{16\pi}{3}\sin\frac{\pi t^2}{3} -\frac{32\pi^2 t^2}{9}\cos\frac{\pi t^2}{3}, \] \[ \ddot y = \frac{32\pi}{3}\cos\frac{\pi t^2}{3} -\frac{64\pi^2 t^2}{9}\sin\frac{\pi t^2}{3}. \]

Подставляя \(t = {{ data.t }}\) (где \(\frac{\pi t^2}{3}=\frac{\pi}{3}\), \(\sin\frac{\pi}{3}=\frac{\sqrt3}{2}\), \(\cos\frac{\pi}{3}=\frac12\)):

\[ \dot x = {{ (data.vx)|gost(4) }},\quad \dot y = {{ (data.vy)|gost(4) }},\quad \ddot x = {{ (data.ax)|gost(4) }},\quad \ddot y = {{ (data.ay)|gost(4) }}\quad(\text{м/с},\ \text{м/с}^2). \]

2.2 Модуль скорости

\[ V(t) = \sqrt{\dot x^2 + \dot y^2} = \sqrt{\left(-\frac{16\pi t}{3} \sin\frac{\pi t^2}{3}\right)^2 + \left(\frac{32\pi t}{3} \cos\frac{\pi t^2}{3}\right)^2} \] \[ V(t) = \frac{16\pi t}{3} \sqrt{\sin^2\frac{\pi t^2}{3} + 4\cos^2\frac{\pi t^2}{3}} = \frac{16\pi t}{3} \sqrt{1 + 3\cos^2\frac{\pi t^2}{3}} \]

В момент \(t = {{ data.t }}\) с:

\[ V = \frac{16\pi}{3}\sqrt{1 + 3\cos^2\frac{\pi}{3}} = \frac{16\pi}{3}\sqrt{1 + 3\cdot\tfrac14} = {{ (data.V)|gost(4) }} \ \text{м/с} \]

2.3 Касательное ускорение

Касательное ускорение — это производная модуля скорости по времени. Дифференцируя \(V=\sqrt{\dot x^2+\dot y^2}\) как сложную функцию, \(\frac{d}{dt}\sqrt{f}=\frac{\dot f}{2\sqrt f}\) с \(f=\dot x^2+\dot y^2\), \(\dot f = 2\dot x\ddot x + 2\dot y\ddot y\), получаем:

\[ a_\tau = \frac{dV}{dt} = \frac{2\dot x\ddot x + 2\dot y\ddot y}{2\sqrt{\dot x^2+\dot y^2}} = \frac{\dot x \ddot x + \dot y \ddot y}{V} \]

Подставляя найденные в п. 2.1 значения:

\[ a_\tau = \frac{({{ (data.vx)|gost(4) }})({{ (data.ax)|gost(4) }}) + ({{ (data.vy)|gost(4) }})({{ (data.ay)|gost(4) }})} {{ '{' }}{{ (data.V)|gost(4) }}{{ '}' }} = {{ (data.a_tau)|gost(4) }} \ \text{м/с}^2 \]

Примечание: Если \(a_\tau > 0\) — скорость возрастает, если \(a_\tau < 0\) — скорость убывает.

2.4 Нормальное ускорение и его проверка

Нормальное ускорение направлено к центру кривизны траектории и характеризует изменение направления скорости. Основная формула — из разложения полного ускорения на касательную и нормальную составляющие \(a^2 = a_\tau^2 + a_n^2\):

\[ a_n = \sqrt{a^2 - a_\tau^2} = \sqrt{({{ (data.a_mod)|gost(4) }})^2 - ({{ (data.a_tau)|gost(4) }})^2} = {{ (data.a_n)|gost(4) }} \ \text{м/с}^2 \]

Проверка (нормальное ускорение, найденное тремя независимыми способами, должно совпадать):

1) Через векторное произведение скорости и ускорения (поперечная к скорости составляющая \(\vec a\)):

\[ a_n = \frac{|\dot x\,\ddot y - \dot y\,\ddot x|}{V} = \frac{|({{ (data.vx)|gost(4) }})({{ (data.ay)|gost(4) }}) - ({{ (data.vy)|gost(4) }})({{ (data.ax)|gost(4) }})|} {{ '{' }}{{ (data.V)|gost(4) }}{{ '}' }} = {{ (data.a_n_cross)|gost(4) }} \ \text{м/с}^2 \]

2) Через радиус кривизны \(\rho\) (см. п. 2.5):

\[ a_n = \frac{V^2}{\rho} = \frac{({{ (data.V)|gost(4) }})^2}{{ '{' }}{{ (data.rho)|gost(4) }}{{ '}' }} = {{ (data.a_n_rho)|gost(4) }} \ \text{м/с}^2 \]

Все три значения совпадают \(\Rightarrow\) расчёт нормального ускорения верен.

2.5 Радиус кривизны траектории

\[ \rho = \frac{V^2}{a_n} = \frac{V^3}{|\dot x \ddot y - \dot y \ddot x|} \]

В момент \(t = {{ data.t }}\) с:

\[ \rho = {{ (data.rho)|gost(4) }} \ \text{м} \]

Физический смысл: радиус кривизны показывает, насколько траектория искривлена. Чем меньше \(\rho\), тем сильнее изгиб.

2.6 Дуговая координата

Дуговая координата \(s(t)\) — длина пути, пройденного точкой вдоль траектории от начального положения. Она равна интегралу от модуля скорости по времени:

\[ s(t) = \int_0^t V(\xi)\,d\xi \]

Обозначение: переменной интегрирования взята буква \(\xi\), а не \(\tau\), чтобы не путать её с касательным ортом \(\vec\tau\) и касательным ускорением \(a_\tau\).

Подставляя найденное в п. 2.2 выражение для модуля скорости \(V(\xi)=\dfrac{16\pi\xi}{3}\sqrt{1+3\cos^2\dfrac{\pi\xi^2}{3}}\), получаем:

\[ s(t) = \int_0^t \frac{16\pi\xi}{3}\sqrt{1+3\cos^2\frac{\pi\xi^2}{3}}\;d\xi \]

Подынтегральная функция содержит \(\cos^2(\pi\xi^2/3)\) под корнем, поэтому первообразная не выражается в элементарных функциях — интеграл вычисляется численно (адаптивная квадратура). В момент \(t = {{ data.t }}\) с:

\[ s = \int_0^{1} \frac{16\pi\xi}{3}\sqrt{1+3\cos^2\frac{\pi\xi^2}{3}}\;d\xi \approx {{ (data.s)|gost(4) }} \ \text{м} \]

3. Полное ускорение точки

Полное ускорение точки складывается из касательной и нормальной составляющих:

\[ \vec a = \vec a_\tau + \vec a_n \]

Модуль полного ускорения:

\[ a = \sqrt{a_\tau^2 + a_n^2} = {{ (data.a_mod)|gost(4) }} \ \text{м/с}^2 \]
